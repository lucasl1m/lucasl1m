## Sobre mim

Desenvolvedor Frontend/Mobile formado em Ciência da Computação pela UFCG, com experiência construindo interfaces escaláveis e de alta performance em React, Next.js, Angular e React Native.

Atuo principalmente no setor financeiro, desde a estruturação de novos projetos até a modernização de sistemas legados que processam milhares de transações por dia. No dia a dia me preocupo tanto em entregar features quanto em manter a base de código estável — automação de testes, integração contínua e um padrão de arquitetura que facilite a vida de quem vem depois.

### Atuação profissional

- **Blockfy** (2025 – atual) — desenvolvimento em React e Next.js, com Server Components, SSR e uma base de componentes reutilizáveis para o design system.
- **Beeteller** (2023 – 2025) — features financeiras em Angular e React Native, integração do protocolo 3DS em fluxos de checkout e manutenção de um sistema legado usado por mais de 40 mil pontos de venda.
- **Educbank** (2022 – 2023) — Design System e interfaces para o fluxo de caixa escolar de uma plataforma usada por mais de 500 escolas.

### Formação

**Bacharelado em Ciência da Computação** — Universidade Federal de Campina Grande (UFCG), 2024
